Search Vendor

You can search Vendor Information on this screen. For searching the Vendor Information, go through following steps :-

How to search the Vendor ?

  1. Search a particular record & click Find Now button. You can Search the Vendor from following way:
    • All : From this you search all the records of Vendor.
    • Vendor : From this you search the Vendor by name. For searching this you have to enter the name of Vendor.
    • City : From this you search the Vendor by city. For searching this you have to enter the name of City.
    • State : From this you search the Vendor by state. For searching this you have to enter the name of State.
    • Country : From this you search the Vendor by country name. For searching this you have to enter the name of Country.
    • Contact Person : From this you search the Vendor by contact person. For searching this you have to enter the name of contact person.
  2. By default searching record is display in the Vendor List.

Vendor List screen contains the following buttons :

Button Name Action
Find Now Find Now button to search the vendor.
Add New Add New button for adding new vendor information.
Close Close button to close the screen.
