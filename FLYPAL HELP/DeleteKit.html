Delete Inspection Kit

You can delete the Kit information on this screen. For deleting the Kit information, go through following steps :-

How to Delete The Inspection Kit ?

  1. Search a particular record & click Find Now button. You can Search the Inspection Kit from following way :-
    • All : From this you search all the records of Inspection Kits.
    • Name : From this you search the Kit by Inspection Kit name. For searching this you have to enter the name of Inspection Kit.
  2. Click on Delete link which you want to delete the record, You get a message box for confirmation.
  3. Click Yes for deletion and No for cancel the action.
