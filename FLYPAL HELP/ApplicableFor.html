Applicable Model List For Part No.

Applicable Model List For Part No. screen contains following buttons :

Button Name Action
Add Add button for adding new model in the Model List.
Back Back button to return back to the Part Information screen.
Next Next button to go to the Opening Balance Information screen.

You can Add/Edit/Delete Model information on this screen.

Note:
Applicable Model List can not be accessible without saving the Part.
