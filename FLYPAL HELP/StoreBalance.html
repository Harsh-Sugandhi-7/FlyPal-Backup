Store Balance Report

To reach the Store Balance Report click Reports link, Select Store Balance link, You get Store Balance Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Store : From this you search the Store Balance by Store Name. For searching this you have to select the Store from drop down list.
  • Part No./Description : From this you search the Store Balance by Part Number or Description. For searching this you have to click Select link on Part List.
