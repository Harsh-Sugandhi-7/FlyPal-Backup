Issue Register Report

To reach the Issue Register Report click Registers link, Select Issue Register link, You get Issue Register Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Date Range : From this you can search the Issue by Date. You can search the Issue Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates of Issue.
  • Doc. Type : From this you search the Issue by Doc Type. The Doc Type may be Receipt or Issue. For searching this you have to enter Receipt/Issue No.
  • Type : From this you search the Issue by Type. The Type may be Vendor, Aircraft or Store. For searching this you have to select the Vendor, Aircraft or Store from drop down list.
  • Rel. Note No. : From this you search the Issue by release note number. For searching this you have to enter the Release Note Number.
  • Serial No. : From this you search the Issue by serial number. For searching this you have to enter the Serial Number.
  • From Store : From this you search the Issue by Store. For searching this you have to select the store from drop down list.
  • Status : From this you search the Issue by Status. For searching this you have to select the status from drop down list. The status may be Opened, Authorized or Cancelled.
  • Part No./Description : From this you search the Issue by Part Number or Description. For searching this you have to click Select link on Part List.
