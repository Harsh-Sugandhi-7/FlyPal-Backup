Add/Edit/Delete Charge

To reach the Charge Information screen on the Icon of Charge Name field, You get Charge Information screen.

How to Add New Charge ?

  1. Enter all the information & click Save button to save the record.

How to Edit The Charge ?

  1. Select the record from list & click Edit button to edit the record.
  2. After editing click Save button to save the record.

How to Delete The Charge ?

  1. Select the record from list & click Delete button, You get a message box for confirmation
  2. Click Yes for deletion & No for cancel the action.

Charge Information screen contains following fields :

Field Name Field Description
Name It is the name of the charge (e.g. Service charge).
Percent Type The percentage type may be Fixed or Variable. You can select it from drop down list.
Charge Type The charge type is on Basic amount, on Particular charges or on Total amount. You can select it from drop down list.
Add minus It may be + or -. If you select + then it's Total Other Charges can be added in the Grand Total. And if you select - then it's Total Other Charges can be deducted from the Grand Total.
Percentage You can enter the percentage of the charge in percentage field. The percentage field is not compulsory if you select the Percent Type "None" (e.g. 4.40).

Charge Information screen contains following buttons :

Button Name Action
Add/Edit Add/Edit button to add/edit the charge information.
Back Back button to return back to the Invoice Charge screen.
