Add/Edit/Delete Order Item

To reach the Order Item screen click Entries link, Select Purchase Order link, You get List of Purchase Order screen. Click Add New button on List of Purchase Order screen, You get Order Details screen. Again click Add button on Order Details screen, You get Order Item screen. 

How to Add New Order Item ?
  1. Enter all the information & click OK button, The record is added successfully in the Order Item List.
  2. After adding click Save button on Order Details screen to save the current record.
How to Edit The Order Item ?
  1. Click Edit link on the selected record, You get Order Item screen.
  2. After editing click OK button, The updated record is added in the Order Item list.
  3. Again click Save button on Order Details screen to save the current record.
How to Delete The Order Item ?
  1. Click Remove link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.
  3. After deleting click Save button to save the current record.

Order Item Details screen contains following buttons :

Button Name Action
OK OK button to save the Order Item information.
Back Back button to return back to the Order Details screen.

Order Item Details screen contains following fields :

Field Name Field Description
Sr. No. Sr. No. is auto generated.
Part No. The Part No. is an alphanumeric code to identify any part. It must be unique (e.g. 000-170000-23).   
Description Description field describes the part (e.g. GLARE SHIELD L.H.).
Quantity You can enter the quantity of that order item (e.g. 12.00).
Rate Rate defines the rate of that quantity. You can enter the rate of that order item (e.g. 450.50).
Amount Amount= Quantity*Rate (e.g. 12.00*12.00=144.00).
Applicable To You can select the Model to which the part is applicable from drop down list. It may be Aircraft, Engines or Ground Equipment etc.
Remark You can enter any remark for this entry in the order item.
Note Any other information associated with that order is entered in the note.

Note:
For selecting the Part & it's Description, click on the Icon of Part No. field, You get Part Stock Status List screen. Search a particular record & click Select link, The selected Part information is added in the Order Item screen.
