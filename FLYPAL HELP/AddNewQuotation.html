Add New Quotation

You can add new Quotation information on this screen. For adding new Quotation information, go through following steps :-

How to Add New Quotation ?

  1. Click Add New button on List of Quotation screen, You get Quotation Details screen.
  2. Enter all the information in Quotation Details screen & click Save button, The record is added successfully in the Quotation List.

Note :
The Quotation can not be save without Quotation Item.
