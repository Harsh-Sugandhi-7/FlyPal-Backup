Add New Alternate Part

You can add new Alternate Part information on this screen. For adding new Alternate Part information, go through following steps :-

How to Add New Alternate Part ?

  1. Search a particular part & click Select Part button. You can Search the Part from following way :
    • All : From this you search all the records of Part.
    • Part No. : From this you search the Part by number. For searching this you have to enter the part number.
    • Description : From this you search the Part by description. For searching this you have to enter the description of Part.
  2. Select the part from Part List screen & click Select link, The selected part is added in the Alternate Part screen.
  3. Again select search option New & enter it's alternate part.
  4. Click Add/Edit button, The Alternate Part is added in the Alternate Part list.
