Pending Order Report

To reach the Pending Order Report click Reminders link, Select Pending Order link, You get Pending Purchase Order Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Date Range : From this you can search the Pending Order by Date. You can search the Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates.
  • Vendor : From this you search the Pending Order by Vendor. For searching this you have to select the vendor from drop down list.
  • Part No./Description : From this you search the Pending Order by Part Number or Description. For searching this you have to click Select link on Part List.
