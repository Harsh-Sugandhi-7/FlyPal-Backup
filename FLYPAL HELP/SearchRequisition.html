Search Requisition

You can search Requisition information on this screen. For searching the Requisition information, go through following steps:-

How to Search The Requisition ?

  1. Search a particular record & click Find Now button. You can Search the Requisition from following way : 
    • All : From this you search all the records of Requisition.
    • Date : From this you can search the Requisition by Date. You can search the Requisition Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates of Requisition.
    • Requisition : From this you search the Requisition by Requisition number. For searching this you have to select the Requisition Text from drop down list & also enter the number which you want to search. 
    • Part Number : From this you search the Requisition by Part Number. For searching this you have to enter the part number.
    • Requesting Location : From this you search the Requisition by Location. For searching this you have to enter the Location.
    • Status : From this you search the Requisition by Status. For searching this you have to select the status from drop down list. The status may be Opened, Authorized or Cancelled.
  2. By default searching record is display in the Requisition List.

List of Requisition screen contains following buttons :

Button Name Action
Find Now Find Now button to search the Requisition.
Add New Add New button for adding new Requisition.
Print Print button to print the List of Requisition.
Close Close button to close the screen.
