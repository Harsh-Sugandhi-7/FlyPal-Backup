Valuation Analysis Report

To reach the Valuation Analysis Report click Analysis link, Select Valuation Analysis link, You get Stock Valuation Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Date Range : From this you can search the Valuation Analysis by Date. You can search the Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates.
  • Store : From this you search the Valuation Analysis by store Name. For searching this you have to select the store from drop down list.
  • Category : From this you search the Valuation Analysis by category. For searching this you have to select the category from drop down list.
  • Vendor : From this you search the Valuation Analysis by Vendor Name. For searching this you have to select the vendor from drop down list.
  • Nomenclature : From this you search the Valuation Analysis by nomenclature. For searching this you have to select the nomenclature from drop down list.
  • Part No./Description : From this you search the Valuation Analysis by Part Number or Description. For searching this you have to click Select link on Part List.
