Add/Edit/Delete Receipt-Cum-Invoice Item

To reach the Receipt-Cum-Invoice Item screen click Entries link, Select Receipt-Cum-Invoice link, You get List of Receipt-Cum-Invoice screen. Click Add New button on List of Receipt-Cum-Invoice screen, You get Receipt-Cum-Invoice Details screen. Again click Add button on Receipt-Cum-Invoice Details screen, You get Receipt-Cum-Invoice Item screen. 

How to Add New Receipt-Cum-Invoice Item ?

  1. Enter all the information & click Ok button, The record is added successfully in the Receipt-Cum-Invoice Item list.
  2. After adding click Save button on Receipt-Cum-Invoice Details screen to save the current record.

How to Edit The Receipt-Cum-Invoice Item ?

  1. Click Edit link on the selected record, You get Receipt-Cum-Invoice Item Details screen.
  2. After editing click Ok button, The updated record is added in the Receipt-Cum-Invoice Item list.
  3. Again click Save button on Receipt-Cum-Invoice Details screen to save the current record.

How to Delete The Receipt-Cum-Invoice Item ?

  1. Click Remove link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.
  3. After deleting click Save button to save the record.

Receipt-Cum-Invoice Details screen contains following buttons :

Button Name Action
Ok Ok button to save the Receipt-Cum-Invoice Item.
Back Back button to return back to the Receipt-Cum-Invoice Details screen.

Receipt-Cum-Invoice Item Details screen contains following fields :

Field Name Field Description
Rele. Note No. Release note number is given by the manufacturer or supplier (e.g. TR.NO/E178).
Date It is the date when the release note number is given (e.g. 06-Dec-2006).
Serial No. Serial number is compulsory only when the selected part is serialized. If the selected part is not serialized then serial number is not compulsory (e.g. 100).
Store Store means the part is stored in which store (e.g. Pune).
Location It is the physical location in the bin/rack where the part is usually stored in the store (e.g. 5G15).
Quantity You can receive the quantity from Order/Issue. Quantity is editable but it never be greater than it's Order/Issue quantity. 
Rate You can enter the rate of that Receipt-Cum-Invoice Item (e.g. 450.50).
Other Charges You can enter the other charges of that Receipt-Cum-Invoice Item (e.g. 2000).
Amount Amount= Quantity*Rate + Other Charges                                 (e.g. 10.00*10.00+500.00=600.00).
Effective Rate Effective Rate = Rate + ((Total Charges/Total Amount)*Rate).
Remark You can enter any remark for this entry in Receipt-Cum-Invoice Item.
Note Any other information associated with that Receipt-Cum-Invoice Item is entered in the note.

Note:
The fields Part Number,  Description, Order/Issue No. & Date fields are selected when you click on the Icon of Part No. field, You get List of Receipt-Cum-Invoice Pending Items screen. Now click Select link on any record, You get Detail information of that Pending receive items. Again click Select link, The Part Number, Description, Order/Issue No. & Date fields are added in the Receipt-Cum-Invoice Item screen.
