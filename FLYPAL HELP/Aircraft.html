Aircraft

To reach the Aircraft screen click Master link, Select AirCraft link, You get Aircraft screen. You can Add/Edit/Delete Aircraft information on this screen.

What do you want to do ?

    Click on this link to see the information about how to Add new Aircraft.
  • Edit Aircraft

  • Delete Aircraft
    Click on this link to see the information about how to Delete the Aircraft.

Aircraft screen contains following fields :

Field Name Field Description
Aircraft Registration No. You can enter the aircraft registration number of an aircraft (e.g. VT-SLK).

Aircraft screen contains following buttons :

Button Name Action
Add/Edit Add/Edit button to add/edit the Aircraft information.
Close Close button to close the screen.
