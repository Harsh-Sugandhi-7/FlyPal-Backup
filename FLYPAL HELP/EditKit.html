Edit Inspection Kit

You can edit the Kit information on this screen. For editing the Kit information, go through following steps :-

How to Edit The Inspection Kit ?

  1. Search a particular record & click Find Now button. You can Search the Inspection Kit from following way :
    • All : From this you search all the records of Inspection Kits.
    • Name : From this you search the Kit by Kit name. For searching this you have to enter the name of Inspection Kit.
  2. Click on Edit link which you want to edit the record, You get Inspection Kit screen.
  3. After editing click Save button, The updated record is added in the Inspection Kit List.
