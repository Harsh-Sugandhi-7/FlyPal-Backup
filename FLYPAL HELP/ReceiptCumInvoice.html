Receipt-Cum-Invoice Details screen contains following fields :

Field Name Field Description
Receipt No. Receipt Number is auto generated (e.g. REC-1999-2000-39).
Invoice No. Invoice Number is auto generated (e.g. INV-1999-2000-76).
Date The date on which the Receipt-Cum-Invoice is being made (e.g. 06-Apr-2005).
Int. Rec. No. Internal Receipt No. is an optional field where the company can key-in an other reference number for the current order (e.g. IRN-123).
Received From The selected order has been received from Vendor, Aircraft or Store.
Select Details Select the identity to whom the parts has been issued.
DC No. The delivery challan number through which the supplier has to send the parts (e.g. DC-321).
DC Date The date on which the Delivery Challan is made (e.g. 11-Aug-2006).
Inv. Number It is the suppliers invoice number (e.g. ENP/DA/01).
Date Invoice date is the suppliers invoice date (e.g. 11-Aug-2004).
Currency It is the name of the currency. You can select it from drop down list (e.g. Rupees).
Factor It is the factor of that selected currency (e.g. 1.00).
Total Total=Amount + Other Charges (e.g. 500.00+1000.00=1500.00).
Total Other Charges Total other charges depends on the invoice charge.                  Total Other Charges=Total*Percentage/100.
Grand Total Grand Total=Total + Total Other Charges                           (e.g. 6131.00+1930.00=8061.00).
Remark You can enter any remark for this entry in Receipt-Cum-Invoice field.
Status The status may be Opened, Authorized or Cancelled. You can select the status from drop down list.

Receipt-Cum-Invoice Details screen contains following buttons :

Button Name Action
Add Add button for adding new Receipt-Cum-Invoice Items.
Add Charge Add Charge button for adding the Charge in the Receipt-Cum-Invoice Charge List.
Save Save button to save the Receipt-Cum-Invoice.
Back Back button to return back to the List of Receipt-Cum-Invoice screen.

Receipt-Cum-Invoice Status :-

  1. Opened :
    The Receipt-Cum-Invoice is saved by default in it's open state. Until it is authorized it can not be printed. We can edit the Receipt-Cum-Invoice in open state only.
  2. Authorized :
    When the Receipt-Cum-Invoice is authorized then only we can print it. Once it is authorize it can not be edit.
  3. Cancelled :
    User can cancel the Receipt-Cum-Invoice but it will be saved with cancelled status. Once it is cancelled it can not be authorized or edit.
