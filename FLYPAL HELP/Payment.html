To reach the List of Payments screen click Entries link, Select Payment link, You get List of Payments screen. You can Add/Edit/Delete/Search Payment information on this screen.

You can Add/Edit/Delete Payment Item information on this screen.

Payment Details screen contains following fields :

Field Name Field Description
Date The date on which the payment is being made (e.g. 20-May-2006).
Vendor Vendor means whose payment is pending. It is a compulsory field (e.g. Indian Oil corporation Ltd).
Currency The name of currency. It is a compulsory field. You can select it from drop down list (e.g. Dollar).
Conversion Factor It is the factor of that selected currency (e.g. 45.55).
Type It is the type of payment. It must be in cheque or cash. You can select it from drop down list.
Cheque Date If the payment is by cheque then cheque date is required (e.g. 20-May-2006).
Cheque No. If the payment is by cheque then cheque number is necessary (e.g. 12345).

Payment Details screen contains following buttons :

Button Name Action
Add Add button for adding new Payment Item information.
Save Save button to save the payment information.
Back Back button to return back to the List of Payments screen.
