Requisition

To reach the List of Requisition screen click Entries link, Select Requisition link, You get List of Requisition screen. You can Add/Edit/Delete/Search Requisition, Requisition Item information on this screen.

You can Add/Edit/Delete Requisition Item on this screen.

Requisition Details screen contains following fields :

Field Name Field Description
No. Requisition No. is auto generated (e.g. REQ-1999-2000-23).
Date The date on which the Requisition is being made (e.g. 14-Feb-2006).
Status The status may be Opened, Authorized, Cancelled. You can select the status from drop down list.
Name The name of the Location. You can select it from drop down list (e.g. Base Location).

Requisition Details screen contains following buttons :

Button Name Action
Add Add button for adding new Requisition Items.
Save Save button to save the Requisition.
Print Print button to print the given Requisition. You can print the Requisition only when it is Authorized.
Back Back button to return back to the List of Requisition screen.

Requisition Status :-

  1. Opened :
    The Requisition is saved by default in it's open state. Until it is authorized it can not be printed. We can edit the Requisition in open state only.
  2. Authorized :
    When the Requisition is authorized then only we can print it. And receive & accept the parts against it .
  3. Cancelled :
    User can cancel the Requisition but it will be saved with Cancelled status. Once it is cancelled it can not be authorized or edit.
