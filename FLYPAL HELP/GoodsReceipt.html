Goods Receipt

You can Add/Edit/Delete Receipt Item information on this screen.

Receipt Details screen contains following fields :

Field Name Field Description
No. Receipt Number is auto generated (e.g. REC-1999-2000-39).
Date The date on which the Receipt is being made (e.g. 12-Mar-2006).
Int. Rec. No. Internal Receipt No. is an optional field where the company can key-in an other reference number for the current order (e.g. IRN-123).
Status The status may be Opened, Authorized or Cancelled. You can select the status from drop down list.
Name The vendor is one who receive the parts against order. You can select the vendor name from drop down list (e.g. Indian Oil corporation Ltd).
DC No. The number through which the supplier has to send the parts (e.g. 98-99/206,207,209).
DC Date The date on which the Delivery Challan is made (e.g. 12-Apr-2005).

Receipt Details screen contains following buttons :

Button Name Action
Add Add button for adding new Receipt Items.
Save Save button to save the receipt information.
Print Print button to print the given receipt. We can print the Receipt only when it is Authorized.
Back Back button to return back to the List of Receipts screen.

Receipt Status :-

  1. Opened :
    The receipt is saved by default in it's open state. Until it is authorized it can not be printed. We can edit the receipt in open state only.
  2. Authorized :
    When the receipt is authorized then only we can print it. Once it is authorized it can not be edit.
  3. Cancelled :
    User can cancel the receipt but it will be saved with Cancelled status. Once it is cancelled it can not be authorized or edit.
