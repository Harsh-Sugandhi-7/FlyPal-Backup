Order Register Report

To reach the Order Register Report click Registers link, Select Order Register link, You get Purchase Order Register Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Date Range : From this you can search the Order by Date. You can search the Order Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates of order.
  • Vendor : From this you search the Order by Vendor. For searching this you have to select the vendor from drop don list.
  • Quotation No. : From this you search the Order by Quotation No. For searching this you have to enter the quotation number.
  • Int. Order No. : From this you search the Order by internal order number. For searching this you have to enter the Internal Order Number.
  • Order No. : From this you search the Order by Order number. For searching this you have to enter the order number.
  • Status : From this you search the Order by Status. For searching this you have to select the status from drop down list. The status may be Opened, Authorized, Amended or Cancelled.
  • Detail Report : From this you search the detail report of that order. For searching this you have to click the checkbox. 
  • Part No./Description : From this you search the Order by Part Number or Description. For searching this you have to click Select link on Part List.
