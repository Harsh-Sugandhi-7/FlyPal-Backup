Add/Delete Model

To reach the List of Models screen click Add button on Requisition Item screen, You get List of Models screen. 

How to Add New Model ?

  1. For selecting the Model click the Checkbox on List of Models screen & click Ok button, The record is added successfully in the Model List.
  2. After adding click Ok button on Requisition Item screen to save the record.

How to Delete The Model ?

  1. Click Remove link on the selected Model, The selected Model is getting deleted from the Model List.
  2. After deleting click Ok button on Requisition Item screen to save the record.

Note:
You can also delete the Models from List of Models screen. For that Uncheck the selected checkbox.
