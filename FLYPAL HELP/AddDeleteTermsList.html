Add/Delete Term

To reach the List of Issue Term screen click Entries link, Select Goods Issue link, You get List of Issue screen. Click Add New button on List of Issue screen, You get Issue Details screen. Again click Add button on Issue Details screen, You get List of Issue Term screen.

How to Add New Term ?

  1. For selecting the Term, click the Checkbox on List of Issue Term screen & click Ok button, The record is added successfully in the Issue Term List.
  2. After adding click Save button on Issue Details screen to save the record.

How to Delete The Term ?

  1. Click Remove link on the selected Term, The selected Term is getting deleted from the list.
  2. After deleting click Save button on Issue Details screen to save the record.

List of Issue Term screen contains following buttons :

Button Name Action
Ok Ok button to add the selected Terms in the Issue Term List.
Back Back button to return back to the Issue Details screen.

Note:
You can also delete the Terms from List of Issue Term screen. For that Uncheck the selected checkbox.
