Purchase Order

You can Add/Edit/Delete Order Item | Add/Delete Order Term | Add/Edit/Delete Term on this screen.

Order Details screen contains following fields :

Field Name Field Description
No. Order No. is auto generated (e.g. ORD-1999-2000-23).
Date The date on which the Order is being made (e.g. 14-Feb-2006).
Delivery Within It is the term where the order is suppose to be delivered in a given days.
Internal Order No. Internal Order No. is an optional field where the company can key-in an other reference number for the current order (e.g. INT-123).
Billing Address Billing address is the address where the supplier is suppose to send the invoice of that order (e.g. BA-111).
Shipping Address Shipping address is the place where the material has to be send (e.g. SA-321).
Name The name of Vendor. You can select it from drop down list (e.g. Bell Helicopter Asia Ltd).
Address The address of the vendor. Selecting the vendor it's address is also comes (e.g. JUHU AERODROME).
Quotation No. It is the suppliers quotation number (e.g. VMJ/SP/6500).
Date Quotation Date means when the quotation of that order is made (e.g. 05-Jan-2000).
Currency The name of currency. It is a compulsory field. You can select it from drop down list (e.g. Rupees).
Factor selecting the currency it's conversion factor is also comes (e.g. 1.00).
Grand Total Grand Total=Quantity*Rate (e.g. 4.00*2.00=8.00).
Status The status may be Opened, Authorized, Cancelled or Amended. You can select the status from drop down list.

Order Details screen contains following buttons :

Button Name Action
Add Add button for adding new Order Items.
Add Add button for adding Terms in Order Term List.
Save Save button to save the purchase order.
Print Print button to print the given Order. You can print the Order only when it is Authorized.
Back Back button to return back to the List of Purchase Order screen.

Order Status :-

  1. Opened :
    The order is saved by default in it's open state. Until it is authorized it can not be printed. We can edit the order in open state only.
  2. Authorized :
    When the order is authorized then only we can print it. And receive & accept the parts against it .
  3. Cancelled :
    User can cancel the order but it will be saved with Cancelled status. Once it is cancelled it can not be authorized or edit.
  4. Amended :
    If the received items are more than purchase order items then amend the actual purchase order. The new Purchase order will be created with it's amended quantity.
