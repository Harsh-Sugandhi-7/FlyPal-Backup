Add/Edit/Delete Payment Item

To reach the Payment screen click Entries link, Select Payment link, You get List of Payments screen. Click Add New button on List of Payments screen, You get Payment Details screen. Again click Add button on Payment Details screen, You get Payment screen.

How to Add New Payment Item ?

  1. Click on the Icon of Invoice field, You get List of Pending Payments screen.
  2. Click Select link on the selected record, The record is added in the Payment screen.
  3. Click Ok button on Payment screen, The record is added successfully in the Payment Item list.
  4. After adding click Save button on Payment Details screen to save the current record.

How to Edit The Payment Item ?

  1. Click Edit link on the selected record, You get Payment screen.
  2. After editing click Ok button on Payment screen, The updated record is added in the Payment Item list.
  3. Again click Save button on Payment Details screen to save the current record.

How to Delete The Payment Item ?

  1. Click Remove link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.
  3. After deleting click Save button to save the record.

Payment Item screen contains following buttons :

Button Name Action
Ok Ok button to save the Payment item information.
Back Back button to return back to the Payment Details screen.
