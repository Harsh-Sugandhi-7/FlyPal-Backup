Add New Requisition

You can add new Requisition information on this screen. For adding new Requisition information, go through following steps :-

How to Add New Requisition ?

  1. Click Add New button on List of Requisition screen, You get Requisition Details screen.
  2. Enter all the information in Requisition Details screen & click Save button, The record is added successfully in the Requisition List.

Note :
The Requisition can not be save without Requisition Item.
