Search Receipt-Cum-Invoice

You can search the Receipt-Cum-Invoice information on this screen. For searching the Receipt-Cum-Invoice information, go through following steps :-

How to Search The Receipt-Cum-Invoice ?

  1. Search a particular record & click Find Now button. You can Search the Receipt-Cum-Invoice from following way :
    • All : From this you search all the records of Receipt-Cum-Invoice.
    • Receipt Date : From this you can search the Receipt-Cum-Invoice by Date. You can search the Receipt-Cum-Invoice Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates of Receipt-Cum-Invoice.
    • Receipt No. : From this you search the Receipt-Cum-Invoice by Receipt Number. For searching this you have to select the Receipt text from drop down list & enter the number which you want to search.
    • Order No. : From this you search the Receipt-Cum-Invoice by Order Number. For searching this you have to select the Order text from drop down list & enter the number which you want to search.
    • Issue No. : From this you search the Receipt-Cum-Invoice by Issue Number. For searching this you have to select the Issue text from drop down list & enter the number which you want to search.
    • Invoice No. : From this you search the Receipt-Cum-Invoice by Invoice Number. For searching this you have to select the Invoice text from drop down list & enter the number which you want to search.
    • Internal Receipt No. : From this you search the Receipt-Cum-Invoice by Internal Receipt No. For searching this you have to enter the internal receipt number.
    • Release Note No. : From this you search the Receipt-Cum-Invoice by Release Note number. For searching this you have to enter the release note number.
    • DC No. : From this you search the Receipt-Cum-Invoice by DC Number. For searching this you have to enter the DC number.
    • Part Number : From this you search the Receipt-Cum-Invoice by Part Number. For searching this you have to enter the part number.
    • Vendor : From this you search the Receipt-Cum-Invoice by Vendor Name. For searching this you have to enter the name of the Vendor.
    • Aircraft : From this you search the Receipt-Cum-Invoice by Aircraft Name. For searching this you have to enter the name of the Aircraft.
    • Store : From this you search the Receipt-Cum-Invoice by Store Name. For searching this you have to enter the name of the Store.
    • Status : From this you search the Receipt-Cum-Invoice by Status. For searching this you have to select the status from drop down list. The status may be Opened, Authorized or Cancelled.
  2. By default searching record is display in the Receipt-Cum-Invoice List.

List of Receipt-Cum-Invoice screen contains following buttons :

Button Name Action
Find Now Find Now button to search the record.
Add New Add New button for adding new Receipt-Cum-Invoice.
