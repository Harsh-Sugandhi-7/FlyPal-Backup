Sales Order Register Report

To reach the Sales Order Register Report click Registers link, Select Sales Order Register link, You get Sales Order Register Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Date Range : From this you can search the Sales Order by Date. You can search the Sales Order Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates of Sales Order.
  • Sales Order No. : From this you search the Sales Order by Sales Order number. For searching this you have to select the Sales Order Text from drop down list & also enter the Sales Order number.
  • Vendor : From this you search the Sales Order by Vendor name. For searching this you have to select the vendor from drop don list.
  • Status : From this you search the Sales Order by Status. For searching this you have to select the status from drop down list. The status may be Opened, Authorized or Cancelled.
  • Part No./Description : From this you search the Sales Order by Part Number or Description. For searching this you have to click Select link on Part List.
