Add/Edit/Delete Receipt Item

To reach the Receipt Item screen click Entries link, Select Goods Receipt link, You get List of Receipts screen. Click Add New button on List of Receipts screen, You get Receipt Details screen. Again click Add button on Receipt Details screen, You get Receipt Item screen. 

How to Add New Receipt Item ?

  1. Enter all the information & click Ok button, The record is added successfully in the Receipt Item list.
  2. After adding click Save button on Receipt Details screen to save the current record.

How to Edit The Receipt Item ?

  1. Click Edit link on the selected record, You get Receipt Item screen.
  2. After editing click Ok button, The updated record is added in the Receipt Item list.
  3. Again click Save button on Receipt Details screen to save the current record.

How to Delete The Receipt Item ?

  1. Click Remove link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.
  3. After deleting click Save button to save the record.

Receipt Item screen contains following buttons :

Button Name Action
Ok Ok button to save the Receipt Item information.
Back Back button to return back to the Receipt Details screen.

Receipt Item screen contains following fields :

Field Name Field Description
Sr. No. Sr. No. is auto generated.
Rel. Note No. Release note number is given by the manufacturer or supplier (e.g. TR.NO/E178).
Date It is the date when release note number is given (e.g. 06-Dec-2006).
Quantity You can receive the quantity from Order/Issue. Quantity is editable, but it never be greater than it's pending quantity. 
Serial No. Serial number is compulsory only when the selected part is serialized. If the selected part is not serialized then serial number is not compulsory.
Store Store means the part is stored in which store (e.g. Pune).
Location It is the physical location in the bin/rack where the part is usually stored in the store (e.g. 5G15).
Remark You can enter any remark for this entry in the receipt item.
Note Any other information associated with that receipt is entered in the note.

Note:
Part Number,  Description, Order/Issue No. & Date fields are selected when you click on the Icon of Part No. field, You get List of Receipt Pending Items screen. Now click Select link on any record, You get Detail information of that Part. Again click Select link, The Part Number, Description, Order/Issue No. & Date fields are getting selected.
