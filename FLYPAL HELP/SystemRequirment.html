System Requirement

To use FlyPal you need to have following Hardware & Software Requirements :-

Software Requirement :-

For running this application following softwares are required :-

  • Windows 2000 / XP / NT Operating System.
  • Dot Net Framework 2003(VB.Net/ASP.Net).
  • SQL Server 2003/MSDE database.

Hardware Requirement :-

For running this application following hardwares are required :-

  • Pentium III / IV Processor. Minimum 2.2GHz speed. 
  • 128,256,512 MB RAM.
  • 108MB Disk Space.
  • 14", 17" colour VGA/mono monitor with mouse and keyboard, Printer for the reports.
