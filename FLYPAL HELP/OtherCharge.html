Other Charge

To reach the List of Other Charge screen click Entries link, Select Other Charge link, You get List of Other Charge screen. You can Add/Edit/Delete/Search Other Charge information on this screen.

You can Add/Delete Invoice Item | Add/Edit/Delete Invoice Charge on this screen.

Other Charge Details screen contains following fields :

Field Name Field Description
No. Other Charge Number is auto generated (e.g. INV-1999-2000-6).
Date The date on which the Other Charge is being made (e.g. 04-May-2006).
Bill Entry No.  
Date It is the bill entry number date (e.g. 11-Aug-2005).
Master Airway Bill No.  
Date It is the House master airway bill number date (e.g. 11-Aug-2004).
House Airway Bill No.  
Date It is the house airway bill number date (e.g. 11-Aug-2006).

Other Charge Details screen contains following buttons :

Button Name Action
Add Add button for adding the Invoices in Invoice List.
Add Add button for adding Charge in Charge List.
Save Save button to save the Other Charge.
Print Print button to print the given Other Charge.
Back Back button to return back to the List of Other Charge screen.
