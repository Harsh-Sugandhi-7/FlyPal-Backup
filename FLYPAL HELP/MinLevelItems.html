Min-Level-Items Report

To reach the Min-Level-Items Report click Reminders link, Select Min-Level-Items link, You get Min Level Part Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Category : From this you search the Min-Level-Items by Category. For searching this you have to select the Category from drop down list.
  • Nomenclature : From this you search the Min-Level-Items by Nomenclature. For searching this you have to select the Nomenclature from drop down list.
  • Part No./Description : From this you search the Min-Level-Items by Part Number or Description. For searching this you have to click Select link on Part List.
