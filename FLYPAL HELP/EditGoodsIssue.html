Edit Goods Issue

You can edit the Goods Issue information on this screen. For editing the Goods Issue information, go through following steps:-

How to Edit The Goods Issue ?

  1. Search a particular record & click Find Now button. You can Search the Issue from following way : 
    • All : From this you search all the records of Issue.
    • Date : From this you can search the Receipt by Date. You can search the Issue Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates of receipt.
    • Issue : From this you search the Issue by Issue number. For searching this you have to select the Issue Text from drop down list & also enter the number which you want to search. 
    • Receipt : From this you search the Issue by Receipt Number. For searching this you have to select the Receipt Text from drop down list & also enter the number which you want to search.
    • Part Number : From this you search the Issue by Part Number. For searching this you have to enter the part number.
    • From Store : From this you search the Issue by Store Name. For searching this you have to enter the name of store.
    • Vendor : From this you search the Issue by Vendor Name. For searching this you have to enter the name of vendor.
    • Aircraft : From this you search the Issue by Aircraft Name. For searching this you have to enter the name of aircraft.
    • Issue To : From this you search the Issue by order i.e. selected order has been issued to Vendor, Aircraft or Store. For searching this you have to select it from drop down list.
    • Release Note No. : From this you search the Issue by Release Note No. For searching this you have to enter the release note number.
    • Serial No. : From this you search the Issue by Serial No. For searching this you have to enter the serial number.
    • Status : From this you search the Issue by Status. For searching this you have to select the status from drop down list. The status may be Opened, Authorized or Cancelled.
  2. Click Edit link which you want to edit the record, You get Issue Details screen.
  3. After editing click Save button, The updated record is added in the Issue List.

Note:
You can edit the Goods Issue only when it is Opened.
