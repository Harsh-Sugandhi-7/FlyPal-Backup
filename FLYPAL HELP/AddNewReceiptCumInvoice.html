Add New Receipt-Cum-Invoice

You can add new Receipt-Cum-Invoice information on this screen. For adding new Receipt-Cum-Invoice information, go through following steps :-

How to Add New Receipt-Cum-Invoice ?

  1. Click Add New button on List of Receipt-Cum-Invoice screen, You get Receipt-Cum-Invoice Details screen.
  2. Enter all the information in Receipt-Cum-Invoice Details screen & click Save button, The record is added successfully in the Receipt-Cum-Invoice List.

Note:
The Receipt-Cum-Invoice can not be save without Receipt-Cum-Invoice Items.
