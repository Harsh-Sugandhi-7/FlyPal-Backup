Opening Balance Information screen contains following buttons :

Button Name Action
Add New Add New button to adding new Opening Balance information.
Back Back button to return back to the Applicable Model List For Part No. screen.
Close Close button to close the screen.

Opening Stock Details screen contains following fields :

Field Name Field Description
Receipt No. Receipt Number is auto generated (e.g. REC-1999-2000-39).
Receipt Date Receipt Date is auto generated (e.g. 06-Mar-2006).
Vendor's Invoice No. Vendor Invoice No. means against which the part have been received (e.g. VIN-15).
Vendor's Invoice Date Vendor Invoice Date means on which date the part is received (e.g. 26-Jan-2006).
Currency It is the name of currency. The currency can be selected from drop down list (e.g. Rupees).
Conversion Factor After selecting the currency it's respective conversion factor is getting selected.
Serial No. Serial number is compulsory only when the selected part is serialized. If the selected part is not serialized then serial number is not compulsory.
Quantity Quantity for that part. But when you select the serialized part at that time quantity is always takes 1.
Landing Rate Landing rate is the effective cost to procure that part which includes the basic rate & other charges like freights insurance etc.
Amount Amount=Quantity*Landing Rate (e.g. 3.00*220.50=661.50).
Release Note No. Release note number is given by the manufacturer or supplier (e.g. TR.NO/E178).
Release Note Date It is the date when the release note number is given (e.g. 06-Dec-2006).
Start Date If the part have life then you can enter the start date of the part (e.g. 06-Mar-2004).
Expiry Date Expiry Date means when the selected part is expired. Expiry date is explicitly given by the manufacturer (e.g. 16-Mar-2006).
Store Store means the part is stored in which store (e.g. Pune).
Location It is the physical location in the bin/rack where the part is usually stored in the store (e.g. rack-5G15).
Remark You can enter any remark for this entry in the opening balance.
Note Any other information associated with the opening balance is entered in the note.

Note:
Opening Balance Information can not be accessible without saving the Part.
