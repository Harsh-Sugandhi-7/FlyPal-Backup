Goods Issue

You can Add/Edit/Delete Issue Item | Add/Delete Issue Term | Add/Edit/Delete Term on this screen.

Issue Details screen contains following fields :

Field Name Field Description
No. Issue Number is auto generated (e.g. ISU-1998-1999-10).
Date The date on which the Issue is being made (e.g. 12-Mar-2000).
Store Store means the part is stored in which store (e.g. Pune).
Status The status may be Opened, Authorized or Cancelled. You can select the status from drop down list.
Issued To The selected order has been issued to Vendor, Aircraft, Discard or Store.
Select Details Select the identity to whom the parts has been issued.
Person The person who is responsible for taking the material from store (e.g. Mr. Sunil).
Remark You can enter any remark for this entry in the issue item.

Issue Details screen contains following buttons :

Button Name Action
Add Add button for adding new Issue Items.
Add Add button for adding the Terms in the Issue Term List.
Save Save button to save the Issue information.
Print Print button to print the given Issue. We can print the Issue only when it is Authorized.
Back Back button to return back to the List of Issues screen.

Issue Status :-

  1. Opened :
    The issue is saved by default in it's open state. Until it is authorized it can not be printed. We can edit the issue in it's open state only.
  2. Authorized :
    When the issue is authorized then only we can print it. Once it is authorize it can not be edit.
  3. Cancelled :
    User can cancel the issue but it will be saved with cancelled status. Once it is cancelled it can not be authorized or edit.
