Part History-Bin Card Report

To reach the Part History For Bin Card Report, click Reports link, Select Part History-Bin Card link, You get Part History For Bin Card Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Part No./Description : From this you search the Order by Part Number or Description. For searching this you have to click Select link on Part List.
  • Release Note No. : From this you search the Bin-Card by release note number. For searching this you have to select the Release Note No. from drop down list.
