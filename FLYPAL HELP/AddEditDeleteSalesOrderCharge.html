Add/Edit/Delete Sales Order Charge

To reach the Sales Order Charge screen click Entries link, Select Sales Order link, You get List of Sales Order screen. Click Add New button on List of Sales Order screen, You get Sales Order Details screen. Again click Add button on Sales Order Details screen, You get Sales Order Charge screen. 

How to Add New Sales Order Charge ?

  1. Enter all the information & click Ok button, The record is added in the Sales Order Charge List.
  2. After adding click Save button on Sales Order Details screen to save the record.

How to Edit The Sales Order Charge ?

  1. Click Edit link on the selected record, You get Sales Order Charge screen.
  2. After editing click Ok button, The updated record is added successfully in the Sales Order Charge List.
  3. Again click Save button Sales Order Details screen to save the record.

How to Delete The Sales Order Charge ?

  1. Click Remove link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.
  3. After deleting click Save button to save the record.

Sales Order Charge screen contains following buttons :

Button Name Action
Ok Ok button for adding the Sales Order Charge in the List.
Back Back button to return back to the Sales Order Details screen.
