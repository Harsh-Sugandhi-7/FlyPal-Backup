Add/Edit/Delete Kit Item

To reach the Inspection Item screen click Master link, Select Inspection Kit link, You get Inspection Kit List screen. Click Add New button on Inspection Kit List screen, You get Inspection Kit screen. Again click Add button on Inspection Kit screen, You get Inspection Item screen. 

How to Add New Kit Item ?

  1. Enter all the information & click OK button, The record is added successfully in the Kit Item list.
  2. After adding click Save button on Inspection Kit screen to save the record.

How to Edit The Kit Item ?

  1. Click Edit link on the selected record, You get Inspection Item screen.
  2. After editing click OK button, The updated record is added in the Kit Item list.
  3. Again click Save button on Inspection Kit screen to save the record.

How to Delete The Kit Item ?

  1. Click Delete link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.
  3. After deleting click Save button on Inspection Kit screen to save the record.

Inspection Item screen contains following buttons :

Button Name Action
Search Search button to search the Part Number.
OK OK button for adding the record in the Kit Item List.
Back Back button to return back to the Inspection Kit screen.

Inspection Item screen contains following fields :

Field Name Field Description
Sr. No. Sr. No. is auto generated.
Part No. The Part No. is an alphanumeric code to identify any part. It must be unique (e.g. 000-170000-23).
Quantity You can enter quantity of the part (e.g. 500).
