Add/Edit/Delete City

To reach the City Information screen click Master link, Select Vendor link, You get Vendor List screen. Click Add New button on Vendor List screen, You get Vendor Details screen. Again click on the Icon of City field, You get City Information screen. 

How To Add New City ?

  1. Enter the City & it's State name & click Add/Edit button, The record is added in the list.

How To Edit The City ?

  1. Click Edit link on the selected record to edit the information.
  2. After editing click Add/Edit button, The updated record is added successfully in the list.

How To Delete The City ?

  1. Click Delete link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.

City Information screen contains following fields :

Field Name Field Description
Name You can enter the name of the city (e.g. Pune).
State Name The name of the state. You can select the State name from drop down list (e.g. Maharashtra).

City Information screen contains following buttons :

Button Name Action
Add/Edit Add/Edit button to add/edit the City information.
Back Back button to return back to the Vendor Details screen.
