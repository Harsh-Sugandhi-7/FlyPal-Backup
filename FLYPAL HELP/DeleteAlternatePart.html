Delete Alternate Part

You can delete the Alternate Part information on this screen. For deleting the Alternate Part information, go through following steps :-

How to Delete The Alternate Part ?

  1. Search a particular part & click Select Part button. You can Search the Part from following way :
    • All : From this you search all the records of Part.
    • Part No. : From this you search the Part by number. For searching this you have to enter the Part number.
    • Description : From this you search the Part by description. For searching this you have to enter the description of Part.
  2. Click Remove link on the selected record, You get a message box for confirmation.
  3. Click Yes for deletion & No for cancel the action.
  4. After deleting click Save button to save the record.
