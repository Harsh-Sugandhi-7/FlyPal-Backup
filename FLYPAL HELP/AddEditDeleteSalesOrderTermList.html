Add/Delete Sales Order Term

To reach the List of Sales Order Term screen click Entries link, Select Sales Order link, You get List of Sales Order screen. Click Add New button on List of Sales Order screen, You get Sales Order Details screen. Again click Add button on Sales Order Details screen, You get List of Sales Order Term screen. 

How to Add New Sales Order Term ?

  1. For selecting the Term click the Checkbox on List of Sales Order Term screen & click Ok button, The record is added successfully in the Sales Order Term List.
  2. After adding click Save button on Sales Order Details screen to save the record.

How to Delete The Sales Order Term ?

  1. Click Remove link on the selected Term, The selected Term is getting deleted from the Sales Order Term List.
  2. After deleting click Save button on Sales Order Details screen to save the record.

List of Sales Order Term screen contains following buttons :

Button Name Action
Ok Ok button to add the selected Terms in Sales Order Term List.
Back Back button to return back to the Sales Order Details screen.

Note:
You can also delete the Terms from List of Sales Order Term screen. For that Uncheck the selected checkbox.
