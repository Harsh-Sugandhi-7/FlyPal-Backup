Aircraft Consumption Report

To reach the Aircraft Consumption Report click Reports link, Select Aircraft Consumption Report link, You get Aircraft Consumption wise Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Date Range : From this you can search the Aircraft Consumption by Date. You can search the Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates.
  • Aircraft : From this you search the Aircraft Consumption by Aircraft Name. For searching this you have to select the Aircraft from drop down list.
  • Category : From this you search the Aircraft Consumption by category. For searching this you have to select the category from drop down list.
