Add/Edit/Delete Quotation Item

To reach the Quotation Item screen click Entries link, Select Quotation link, You get List of Quotation screen. Click Add New button on List of Quotation screen, You get Quotation Details screen. Again click Add button on Quotation Details screen, You get Quotation Item screen. 

How to Add New Quotation Item ?
  1. Enter all the information & click Ok button, The record is added successfully in the Quotation Item List.
  2. After adding click Save button on Quotation Details screen to save the current record.
How to Edit The Quotation Item ?
  1. Click Edit link on the selected record, You get Quotation Item screen.
  2. After editing click Ok button, The updated record is added in the Quotation Item list.
  3. Again click Save button on Quotation Details screen to save the current record.
How to Delete The Quotation Item ?
  1. Click Remove link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.
  3. After deleting click Save button to save the current record.

Quotation Details screen contains following buttons :

Button Name Action
Ok Ok button to save the Quotation Item information.
Back Back button to return back to the Quotation Details screen.

Quotation Item screen contains following fields :

Field Name Field Description
Quantity You can enter the quantity of that quotation item (e.g. 12.00).
Rate You can enter the rate of that quotation item (e.g. 450.50).
Other Charges You can enter the other charges of that quotation item (e.g. 2000).
Amount Amount= Quantity*Rate + Other Charges                                    (e.g. 10.00*10.00+100.00=200.00).
Effective Rate Effective Rate = Rate + ((Total Charges/Total Amount)*Rate).
Applicable To You can select the Model to which the part is applicable. It may be Aircraft, Engines or Ground Equipment etc.
Remarks You can enter any remark for this entry in the Quotation item.
Note Any other information associated with that Quotation is entered in the note.

Note:
The fields of Quotation Item & Enquiry Item Information are selected when you click on the Icon of Part No. field, You get List of Parts & it's Pending Enquiries screen. Search a particular record & click Select link, You get Detail information of the Part. Again click Select link, The information of that part is added in the Quotation Item screen.
