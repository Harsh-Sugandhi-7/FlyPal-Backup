Sales Order

To reach the List of Sales Order screen click Entries link, Select Sales Order link, You get List of Sales Order screen. You can Add/Edit/Delete/Search Sales Order, Sales Order Item, Sales Order Term & Sales Order Charge information on this screen.

You can Add/Edit/Delete Sales Order Item | Add/Delete Sales Order Term | Add/Edit/Delete Term | Add/Edit/Delete Sales Order Charge | Add/Edit/Delete Charge on this screen.

Sales Order Details screen contains following fields :

Field Name Field Description
No. Sales Order Number is auto generated (e.g. SLO-1999-2000-6).
Date The date on which the Sales Order is being made (e.g. 04-May-2006).
Customer Ref. No. Customer Ref. No. is an optional field where the company can key-in an other reference number for the current Sales Order (e.g. INT-123)
Status The status may be Opened, Authorized or Cancelled. You can select the status from drop down list.
Name Vendor means to whom the Sales Order is made. It is a compulsory field (e.g. Indian Oil corporation Ltd).
Address It is an address of the vendor. Selecting the vendor it's address is also comes (e.g. JUHU AERODROME).
Currency It is the name of currency (e.g. Rupees).
Factor It is the factor of that selected currency (e.g. 1.00).
Total Total=Quantity*Rate + Other Charges                                       (e.g. 10.00*10.00+100.00=200.00).
Total Other Charges Total other charges depends on Sales Order charge.                    Total Other Charges=Total*Percentage/100                           (e.g. 150.00*2.00/100.00=3.00).
Grand Total Grand Total=Total + Total Other Charges                             (e.g. 6131.00+1930.00=8061.00).

Sales Order Details screen contains following buttons :

Button Name Action
Add Add button for adding new Sales Order Items.
Add Add button for adding Terms in Sales Order Term List.
Add Add button for adding new Charges in Sales Order Charge List.
Save Save button to save the Sales Order.
Print Print button to print the given Sales Order. You can print the Sales Order only when it is Authorized.
Back Back button to return back to the List of Sales Order screen.

Sales Order Status :-

  1. Opened :
    The Sales Order is saved by default in it's open state. Until it is authorized it can not be printed. We can edit the Sales Order in open state only.
  2. Authorized :
    When the Sales Order is authorized then only we can print it. Once it is authorize it can not be edit.
  3. Cancelled :
    User can cancel the Sales Order but it will be saved with cancelled status. Once it is cancelled it can not be authorized or edit.
