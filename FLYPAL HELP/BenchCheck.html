Bench Check Report

To reach the Bench Check Report click Reports link, Select Bench Check Report link, You get Bench Check Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Store : From this you search the Bench Check by Store. For searching this you have to select the Store from drop down list.
  • Part No./Description : From this you search the Bench Check by Part Number or Description. For searching this you have to click Select link on Part List.
