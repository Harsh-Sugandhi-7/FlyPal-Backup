Edit Enquiry

You can edit the Enquiry information on this screen. For editing the Enquiry information, go through following steps :-

How to Edit The Enquiry ?

  1. Search a particular record & click Find Now button. You can Search the Enquiry from following way : 
    • All : From this you search all the records of Enquiry.
    • Date : From this you can search the Enquiry by Date. You can search the Enquiry Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates of Enquiry.
    • Enquiry : From this you search the Enquiry by Enquiry number. For searching this you have to select the Enquiry Text from drop down list & also enter the number which you want to search. 
    • Part Number : From this you search the Enquiry by Part Number. For searching this you have to enter the part number.
    • Vendor : From this you search the Enquiry by Vendor name. For searching this you have to enter the vendor name.
    • Status : From this you search the Enquiry by Status. For searching this you have to select the status from drop down list. The status may be Opened, Authorized or Cancelled.
  2. Click Edit link which you want to edit the record, You get Enquiry Details screen.
  3. After editing click Save button, The updated record is added in the Enquiry List.

Note:
You can edit the Enquiry only when it is Opened.
