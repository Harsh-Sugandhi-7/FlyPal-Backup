Add/Edit/Delete User

To reach the User screen click User Manager, Select User Rights, You get User screen. You can Add/Edit/Delete User on this screen. To add new User information, go through following steps :-

How to Add New User ?

  1. Enter all the information in User screen & click Save button to save the record.

How to Edit The User ?

  1. Select the user name from list & click Edit button, The selected user is display in the screen.
  2. After editing click Save button to save the record.

How to Delete User ?

  1. Select the user name from list and click Delete button, You get a message box for confirmation.
  2. Click Yes for deletion and No for cancel the action.

User screen contains following fields :

Field Name Field Description
User Name It is the name of the user (e.g. admin).
Password You can enter the password of the user. It should never be less than 4 characters.
Confirm Password Again enter the same password for confirmation.

User screen contains following buttons :

Button Name Action
Save Save button to save the user.
Role Role button to open the User's Role screen.
Add New button for adding new user.
Edit Edit button to edit the selected user.
Delete Delete button to delete the selected user.
Close Close button to close the screen.

Note:
Save button is Enabled when you enter the User Name. Otherwise it is Disabled.
