Getting Started

A user account defines the actions which user can perform in FlyPal application. The privileges assigned to each user. A user must be a member of FlyPal application. The permissions and rights of FlyPal application granted to it's members only. You must be login to use this application. The default User Name & Password is "admin". This is the first screen of an application. After that you get the main screen.

Note :
Password : The password field may contain uppercase letters, lowercase letters, special characters or numbers only. The more random the sequences of characters, more secure the password.

How to Login ?

  1. Enter correct username and password in respective fields.
  2. Click Login button to enter into the application.
  3. Click Cancel button to exit from the application.
