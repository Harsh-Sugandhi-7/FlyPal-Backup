Search Alternate Part

You can search the Alternate Part information on this screen. For searching the Alternate Part information, go through following steps :-

How to Search New Alternate Part ?

  1. Click Select Part button on Alternate Part screen.
  2. Select the part from Part List screen & click Select link, The selected part is added in the Alternate Part screen.
  3. Search a particular Alternate Part & click Add/Edit button. You can Search the Alternate Part from following way :
    • New : From this you can add new Alternate part in the Alternate Part list.
    • Existing : From this you search the existing Alternate Parts. 
  4. Click the Checkbox on Part List screen & click Ok button, The selected part is added in the Alternate Part List.
