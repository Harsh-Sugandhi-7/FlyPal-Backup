Part List Report

To reach the Part List Report click Reports link, Select Part List link, You get Part Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Category : From this you search the Part List by category. For searching this you have to select the category from drop down list.
  • Nomenclature : From this you search the Part List by nomenclature. For searching this you have to select the nomenclature from drop down list.
  • Part No./Description : From this you search the Part List by Part Number or Description. For searching this you have to click Select link on Part List.
