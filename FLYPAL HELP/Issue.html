Part History-Issue Report

To reach the Part History For Issue Report, click Reports link, Select Part History-Issue link, You get Part History For Issue Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Part No./Description : From this you search the Order by Part Number or Description. For searching this you have to click Select link on Part List.
