Vendor

To reach the Vendor List screen click Master link, Select Vendor link, You get Vendor List screen. You can Add/Edit/Delete/Search Vendor information on this screen.

What do you want to do?
  • Add New Vendor
    Click on this link to see the information about how to Add New Vendor.
  • Edit Vendor
    Click on this link to see the information about how to Edit the Vendor.
  • Delete Vendor
    Click on this link to see the information about how to Delete the Vendor.
  • Search Vendor
    Click on this link to see the information about how to Search the Vendor.

You can Add/Edit/Delete City | Add/Edit/Delete State | Add/Edit/Delete Country on this screen.

Vendor Details screen contains following fields :

Field Name Field Description
Name Vendor is nothing but supplier. It supply the goods as per orders (e.g. Bell Helicopter Asia Ltd).
Address The address of vendor (e.g. JUHU AERODROME).
City The city of the vendor (e.g. Pune).
State The state of the vendor (e.g. Maharashtra).
Country The country of the vendor (e.g. India).
Phone1 The phone number of the vendor (e.g. 020-27995566).
Phone2 It is the alternate phone number of the vendor (e.g. 020-2556767).
Phone3 It is the alternate phone number of the vendor (e.g. 020-26345867).
Fax You can enter the fax number of the vendor (e.g. 22-28644352).
Email It is the email address of the vendor. The e-mail address contains numbers, characters or special characters (e.g. jaitha@vsnl.com).
Contact Person The contact person is one to whom you want to contact. If vendor is not available then you can contact to it's contact person (e.g. Mr. SUDHIR SAXSENA).

Vendor Details screen contains following buttons :

Button Name Action
Save Save button to save the vendor information.
Back Back button to return back to the Vendor List screen.
