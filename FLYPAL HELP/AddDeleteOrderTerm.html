Add/Delete Order Term

To reach the Order Term screen click Entries link, Select Purchase Order link, You get List of Purchase Order screen. Click Add New button on List of Purchase Order screen, You get Order Details screen. Again click Add button on Order Details screen, You get List of Order Term screen. 

How to Add New Order Term ?

  1. For selecting the Term click the Checkbox on List of Order Term screen & click Ok button, The record is added successfully in the Order Term List.
  2. After adding click Save button on Order Details screen to save the record.

How to Delete The Order Term ?

  1. Click Remove link on the selected Term, The selected Term is getting deleted from the Order Term List.
  2. After deleting click Save button on Order Details screen to save the record.

List of Order Term screen contains following buttons :

Button Name Action
Ok Ok button to add the selected Terms in the Order Term List.
Back Back button to return back to the Purchase Order screen.

Note:
You can also delete the Terms from List of Order Term screen. For that Uncheck the selected checkbox.
