Quotation Details screen contains following fields :

Field Name Field Description
No. Quotation Number is auto generated (e.g. QUO-1999-2000-6).
Date The date on which the Quotation is being made (e.g. 04-May-2006).
Status The status may be Opened, Authorized or Cancelled. You can select the status from drop down list.
Name Vendor means to whom the Quotation is made. It is a compulsory field (e.g. Indian Oil corporation Ltd).
Address It is an address of the vendor. Selecting the vendor it's address is also comes (e.g. JUHU AERODROME).
Currency It is the name of currency (e.g. Rupees).
Factor It is the factor of that selected currency (e.g. 1.00).
Total Total=Quantity*Rate + Other Charges                                       (e.g. 10.00*10.00+100.00=200.00).
Total Other Charges Total other charges depends on Quotation charge.                    Total Other Charges=Total*Percentage/100                           (e.g. 150.00*2.00/100.00=3.00).
Grand Total Grand Total=Total + Total Other Charges                             (e.g. 6131.00+1930.00=8061.00).

Quotation Details screen contains following buttons :

Button Name Action
Add Add button for adding new Quotation Items.
Add Add button for adding Terms in Quotation Term List.
Add Add button for adding new Charges in Quotation Charge List.
Save Save button to save the Quotation.
Print Print button to print the given Quotation. You can print the Quotation only when it is Authorized.
Back Back button to return back to the List of Quotation screen.

Quotation Status :-

  1. Opened :
    The Quotation is saved by default in it's open state. Until it is authorized it can not be printed. We can edit the Quotation in open state only.
  2. Authorized :
    When the Quotation is authorized then only we can print it. Once it is authorize it can not be edit.
  3. Cancelled :
    User can cancel the Quotation but it will be saved with cancelled status. Once it is cancelled it can not be authorized or edit.
