Enquiry Register Report

To reach the Enquiry Register Report click Registers link, Select Enquiry Register link, You get Enquiry Register Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Date Range : From this you can search the Enquiry by Date. You can search the Enquiry Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates of Enquiry.
  • Enquiry No. : From this you search the Enquiry by Enquiry number. For searching this you have to select the Enquiry Text from drop down list & also enter the Enquiry number.
  • Vendor : From this you search the Enquiry by Vendor name. For searching this you have to select the vendor from drop don list.
  • Status : From this you search the Enquiry by Status. For searching this you have to select the status from drop down list. The status may be Opened, Authorized or Cancelled.
  • Part No./Description : From this you search the Enquiry by Part Number or Description. For searching this you have to click Select link on Part List.
