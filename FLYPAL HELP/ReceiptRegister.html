Receipt Register Report

To reach the Receipt Register Report click Registers link, Select Receipt Register link, You get Receipt Register Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Date Range : From this you can search the Receipt by Date. You can search the Receipt Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates of Receipt.
  • Doc Type : From this you search the Receipt by Doc Type. The Doc Type may be Receipt, Issue or Order. For searching this you have to enter Receipt/Order/Issue No.
  • Type : From this you search the Receipt by Type. For searching this you have to select the Vendor from drop down list.
  • Int. Rece. No. : From this you search the Receipt by internal Receipt number. For searching this you have to enter the Internal Receipt Number.
  • Rel. Note No. : From this you search the Receipt by release note number. For searching this you have to enter the Release Note Number.
  • DC No. : From this you search the Receipt by DC number. For searching this you have to enter the DC number.  
  • Status : From this you search the Receipt by Status. For searching this you have to select the status from drop down list. The status may be Opened, Authorized or Cancelled.
  • Part No./Description : From this you search the Receipt by Part Number or Description. For searching this you have to click Select link on Part List.
