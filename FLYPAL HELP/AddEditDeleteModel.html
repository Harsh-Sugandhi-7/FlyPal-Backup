Add/Edit/Delete Model

To reach the Model screen click Master link, Select Part link, You get Part List screen. Click Edit link on Part List screen, You get Part Information screen. Click Next button on Part Information screen, You get Applicable Model List For Part No. screen. Again click on the Icon of Model field, You get Model screen. 

How to Add New Model ?

  1. Enter all the information & click Add/Edit button, The record is added in the list.

How to Edit The Model ?

  1. Click Edit link on the selected record to edit the information.
  2. After editing click Add/Edit button, The updated record is added successfully in the list.

How to Delete The Model ?

  1. Click Delete link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.

Model screen contains following fields :

Field Name Field Description
Name The name of the model (e.g. BELL 206L-4).
Type The model type may be like Aircraft, Ground Equipment or Engine etc. You can select the model type from drop down list.

Model screen contains following buttons :

Button Name Action
Add/Edit Add/Edit button to add/edit the Model information.
Back Back button to return back to the Applicable Model List For Part No. screen.
