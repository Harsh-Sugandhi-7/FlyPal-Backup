Requisition Register Report

To reach the Requisition Register Report click Registers link, Select Requisition Register link, You get Requisition Register Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Date Range : From this you can search the Requisition by Date. You can search the Requisition Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates of Requisition.
  • Requisition No. : From this you search the Requisition by Requisition number. For searching this you have to select the Requisition Text from drop down list & also enter the Requisition number.
  • Location : From this you search the Requisition by Location. For searching this you have to select the location from drop don list.
  • Status : From this you search the Requisition by Status. For searching this you have to select the status from drop down list. The status may be Opened, Authorized or Cancelled.
  • Part No./Description : From this you search the Requisition by Part Number or Description. For searching this you have to click Select link on Part List.
