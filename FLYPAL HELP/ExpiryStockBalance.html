Expiry Stock Balance Report

To reach the Expiry Stock Balance Report click Reports link, Select Expiry Stock Balance link, You get Expiry Stock Balance Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Date : From this you can search the Expiry Stock Balance by Start Date. For searching this you have to select the Start Date from drop down list.
  • Store : From this you search the Expiry Stock Balance by Store Name. For searching this you have to select the Store from drop down list.
