Add/Edit/Delete Quotation Charge

To reach the Quotation Charge screen click Entries link, Select Quotation link, You get List of Quotation screen. Click Add New button on List of Quotation screen, You get Quotation Details screen. Again click Add button on Quotation Details screen, You get Quotation Charge screen. 

How to Add New Quotation Charge ?

  1. Enter all the information & click Ok button, The record is added in the Quotation Charge List.
  2. After adding click Save button on Quotation Details screen to save the record.

How to Edit The Quotation Charge ?

  1. Click Edit link on the selected record, You get Quotation Charge screen.
  2. After editing click Ok button, The updated record is added successfully in the Quotation Charge List.
  3. Again click Save button Quotation Details screen to save the record.

How to Delete The Quotation Charge ?

  1. Click Remove link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.
  3. After deleting click Save button to save the record.

Quotation Charge screen contains following buttons :

Button Name Action
Ok Ok button for adding the Quotation Charge in the List.
Back Back button to return back to the Quotation Details screen.
