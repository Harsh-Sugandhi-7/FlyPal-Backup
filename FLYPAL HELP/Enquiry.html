Enquiry

To reach the List of Enquiry screen click Entries link, Select Enquiry link, You get List of Enquiry screen. You can Add/Edit/Delete/Search Enquiry, Enquiry Item & Enquiry Term information on this screen.

  • Search Enquiry

You can Add/Edit/Delete Enquiry Item | Add/Delete Enquiry Term | Add/Edit/Delete Term on this screen.

Enquiry Details screen contains following fields :

Field Name Field Description
No. Enquiry No. is auto generated (e.g. ENQ-1999-2000-23).
Date The date on which the Enquiry is being made (e.g. 14-Feb-2006).
Source It is the source of Enquiry. The enquiry source may be from Telephone, Fax or E-mail etc.
Name The name of Vendor. You can select it from drop down list (e.g. Bell Helicopter Asia Ltd).
Address It is the address of the vendor. Selecting the vendor it's address is also comes (e.g. JUHU AERODROME).
Status The status may be Opened, Authorized or Cancelled. You can select the status from drop down list.

Enquiry Details screen contains following buttons :

Button Name Action
Add Add button for adding new Enquiry Items.
Add Add button for adding Terms in Enquiry Term List.
Save Save button to save the Enquiry.
Print Print button to print the given Enquiry. You can print the Enquiry only when it is Authorized.
Back Back button to return back to the List of Enquiry screen.

Enquiry Status :-

  1. Opened :
    The enquiry is saved by default in it's open state. Until it is authorized it can not be printed. We can edit the enquiry in open state only.
  2. Authorized :
    When the enquiry is authorized then only we can print it. And receive & accept the parts against it .
  3. Cancelled :
    User can cancel the enquiry but it will be saved with Cancelled status. Once it is cancelled it can not be authorized or edit.
