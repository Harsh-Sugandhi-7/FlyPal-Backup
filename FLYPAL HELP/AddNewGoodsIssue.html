Add New Goods Issue

You can add new Goods Issue information on this screen. For adding new Goods Issue information, go through following steps:-

How to Add New Goods Issue ?

  1. Click Add New button on List of Issue screen, You get Issue Details screen.
  2. Enter all the information in Issue Details screen & click Save button, The record is added successfully in the List of Issue screen.

Note:
The Issue can not be save without Issue Items.
