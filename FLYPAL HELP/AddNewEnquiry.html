Add New Enquiry

You can add new Enquiry information on this screen. For adding new Enquiry information, go through following steps :-

How to Add New Enquiry ?

  1. Click Add New button on List of Enquiry screen, You get Enquiry Details screen.
  2. Enter all the information in Enquiry Details screen & click Save button, The record is added successfully in the Enquiry List.

Note :
The Enquiry can not be save without Enquiry Item.
