Search Payment

You can search the Payment information on this screen. For searching the Payment information, go through following steps :-

How to Search The Payment ?

  1. Search a particular record & click Find Now button. You can Search the payment from following way :
    • Date : From this you can search the payment by Date. For searching this you have to select the From Date & To Date from drop down list.
    • Vendor : From this you search the payment by Vendor Name. For searching this you have to enter the vendor name.
  2. By default searching record is display in the Payment List.

List of Payments screen contains following buttons :

Button Name Action
Find Now Find Now button to search the payment.
Add New Add New button for adding new payment information.
Close Close button to close the screen.
