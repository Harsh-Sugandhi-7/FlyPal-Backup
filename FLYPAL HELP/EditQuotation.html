Edit Quotation

You can edit the Quotation information on this screen. For editing the Quotation information, go through following steps :-

How to Edit The Quotation ?

  1. Search a particular record & click Find Now button. You can Search the Quotation from following way : 
    • All : From this you search all the records of Quotation.
    • Date : From this you can search the Quotation by Date. You can search the Quotation Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates of Quotation.
    • Quotation : From this you search the Quotation by Quotation number. For searching this you have to select the Quotation Text from drop down list & also enter the number which you want to search. 
    • Part Number : From this you search the Quotation by Part Number. For searching this you have to enter the part number.
    • Vendor : From this you search the Quotation by Vendor name. For searching this you have to enter the vendor name.
    • Enquiry : From this you search the Enquiry by Enquiry number. For searching this you have to select the Enquiry Text from drop down list & also enter the number which you want to search. 
    • Status : From this you search the Quotation by Status. For searching this you have to select the status from drop down list. The status may be Opened, Authorized or Cancelled.
  2. Click Edit link which you want to edit the record, You get Quotation Details screen.
  3. After editing click Save button, The updated record is added in the Quotation List.

Note:
You can edit the Quotation only when it is Opened.
