Quotation Register Report

To reach the Quotation Register Report click Registers link, Select Quotation Register link, You get Quotation Register Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Date Range : From this you can search the Quotation by Date. You can search the Quotation Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates of Quotation.
  • Quotation No. : From this you search the Quotation by Quotation number. For searching this you have to select the Quotation Text from drop down list & also enter the Quotation number.
  • Vendor : From this you search the Quotation by Vendor name. For searching this you have to select the vendor from drop don list.
  • Status : From this you search the Quotation by Status. For searching this you have to select the status from drop down list. The status may be Opened, Authorized or Cancelled.
  • Part No./Description : From this you search the Quotation by Part Number or Description. For searching this you have to click Select link on Part List.
