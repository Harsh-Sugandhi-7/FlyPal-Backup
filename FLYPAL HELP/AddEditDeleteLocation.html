Add/Edit/Delete Location

To reach the Location screen click Master link, Select Store link, You get Store screen. Again click on the Icon of Location field, You get Location screen.

How to Add New Location ?

  1. Enter the name of Location & click Add/Edit button, The record is added in the list.

How to Edit The Location ?

  1. Click Edit link on the selected record to edit the information.
  2. After editing click Add/Edit button, The updated record is added successfully in the list.

How to Delete The Location ?

  1. Click Delete link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.

Location screen contains following buttons :

Button Name Action
Add/Edit Add/Edit button to add/edit the Location information.
Back Back button to return back to the Store screen.
