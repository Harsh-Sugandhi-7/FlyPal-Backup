Add New Purchase Order

You can add new Purchase Order information on this screen. For adding new Purchase Order information, go through following steps :-

How to Add New Purchase Order ?

  1. Click Add New button on List of Purchase Order screen, You get Order Details screen.
  2. Enter all the information in Order Details screen & click Save button, The record is added successfully in the Order List.

Note :
The Purchase Order can not be save without Order Items.
