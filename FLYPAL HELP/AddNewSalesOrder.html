Add New Sales Order

You can add new Sales Order information on this screen. For adding new Sales Order information, go through following steps :-

How to Add New Sales Order ?

  1. Click Add New button on List of Sales Order screen, You get Sales Order Details screen.
  2. Enter all the information in Sales Order Details screen & click Save button, The record is added successfully in the Sales Order List.

Note :
The Sales Order can not be save without Sales Order Item.
