Add/Edit/Delete Sales Order Item

To reach the Sales Order Item screen click Entries link, Select Sales Order link, You get List of Sales Order screen. Click Add New button on List of Sales Order screen, You get Sales Order Details screen. Again click Add button on Sales Order Details screen, You get Sales Order Item screen. 

How to Add New Sales Order Item ?

  1. Enter all the information & click Ok button, The record is added successfully in the Sales Order Item List.
  2. After adding click Save button on Sales Order Details screen to save the current record.

How to Edit The Sales Order Item ?

  1. Click Edit link on the selected record, You get Sales Order Item screen.
  2. After editing click Ok button, The updated record is added in the Sales Order Item list.
  3. Again click Save button on Sales Order Details screen to save the current record.

How to Delete The Sales Order Item ?

  1. Click Remove link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.
  3. After deleting click Save button to save the current record.

Sales Order Details screen contains following buttons :

Button Name Action
Ok Ok button to save the Sales Order Item information.
Back Back button to return back to the Sales Order Details screen.

Sales Order Item screen contains following fields :

Field Name Field Description
Quantity You can enter the quantity of that Sales Order item (e.g. 12.00).
Rate You can enter the rate of that Sales Order item (e.g. 450.50).
Other Charges You can enter the other charges of that Sales Order item (e.g. 2000).
Amount Amount= Quantity*Rate + Other Charges                                    (e.g. 10.00*10.00+100.00=200.00).
Effective Rate Effective Rate = Rate + ((Total Charges/Total Amount)*Rate).
Applicable To You can select the Model to which the part is applicable. It may be Aircraft, Engines or Ground Equipment etc.
Remarks You can enter any remark for this entry in the Sales Order item.
Note Any other information associated with that Sales Order is entered in the note.

Note:
The fields of Sales Order Item & Quotation Item Information are selected when you click on the Icon of Part No. field, You get List of Parts & it's Pending Quotations screen. Search a particular record & click Select link, You get Detail information of the Part. Again click Select link, The information of that part is added in the Sales Order Item screen.
