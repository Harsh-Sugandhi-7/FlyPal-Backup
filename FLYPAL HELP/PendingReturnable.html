Pending Returnable Report

To reach the Pending Returnable Report click Reminders link, Select Pending Returnable link, You get Pending Returnable Parts Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Aircraft : From this you search the Pending Returnable by Aircraft. For searching this you have to select the Aircraft name from drop down list.
  • Vendor : From this you search the Pending Returnable by Vendor. For searching this you have to select the vendor name from drop down list.
  • Store : From this you search the Pending Returnable by store. For searching this you have to select the store name from drop down list.
  • Part No./Description : From this you search the Pending Returnable by Part Number or Description. For searching this you have to click Select link on Part List.
