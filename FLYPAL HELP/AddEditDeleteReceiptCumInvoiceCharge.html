Add/Edit/Delete Receipt-Cum-Invoice Charge

To reach the Receipt-Cum-Invoice Charge screen click Entries link, Select Receipt-Cum-Invoice link, You get List of Receipt-Cum-Invoice screen. Click Add New button on List of Receipt-Cum-Invoice screen, You get Receipt-Cum-Invoice Details screen. Again click Add button on Receipt-Cum-Invoice Details screen, You get Invoice Charge screen. 

How to Add New Receipt-Cum-Invoice Charge ?

  1. Enter all the information & click Ok button, The record is added in the Receipt-Cum-Invoice Charge list.
  2. After adding click Save button on Receipt-Cum-Invoice Details screen to save the current record.

How to Edit The Receipt-Cum-Invoice Charge ?

  1. Click Edit link on the selected record, You get Invoice Charge screen.
  2. After editing click Ok button, The updated record is added in the Receipt-Cum-Invoice Charge list.
  3. Again click Save button on Receipt-Cum-Invoice Details screen to save the current record.

How to Delete The Receipt-Cum-Invoice Charge ?

  1. Click Remove link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.
  3. After deleting click Save button to save the record.

Receipt-Cum-Invoice Details screen contains following buttons :

Button Name Action
Ok Ok button for adding new Receipt-Cum-Invoice charge in the list.
Back Back button to return back to the Receipt-Cum-Invoice Details screen.
