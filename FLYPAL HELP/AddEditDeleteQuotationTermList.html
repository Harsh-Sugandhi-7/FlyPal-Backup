Add/Delete Quotation Term

To reach the List of Quotation Term screen click Entries link, Select Quotation link, You get List of Quotation screen. Click Add New button on List of Quotation screen, You get Quotation Details screen. Again click Add button on Quotation Details screen, You get List of Quotation Term screen. 

How to Add New Quotation Term ?

  1. For selecting the Term click the Checkbox on List of Quotation Term screen & click Ok button, The record is added successfully in the Quotation Term List.
  2. After adding click Save button on Quotation Details screen to save the record.

How to Delete The Quotation Term ?

  1. Click Remove link on the selected Term, The selected Term is getting deleted from the Quotation Term List.
  2. After deleting click Save button on Quotation Details screen to save the record.

List of Quotation Term screen contains following buttons :

Button Name Action
Ok Ok button to add the selected Terms in Quotation Term List.
Back Back button to return back to the Quotation Details screen.

Note:
You can also delete the Terms from List of Quotation Term screen. For that Uncheck the selected checkbox.
