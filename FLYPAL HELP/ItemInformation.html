Part Information

Part Information screen contains following fields :

Field Name Field Description
Part No. The Part No. is an alphanumeric code to identify any part. It must be unique (e.g. 000-170000-23).
Nomenclature
 Nomenclature is a grouping based on the description of the part (e.g. AGS).
Description Description field describes the part (e.g. GLARE SHIELD L.H.).
Unit Unit of measurement by which it's part is issued or receipt (e.g. KG).
Location It is the physical location in the bin/rack where the part is usually stored in the store (e.g. 5G15).
Category Category is the operational/functional grouping of the part number (e.g. CONSUMABLE).
Approximate Rate The value used for ordering the particular part.
ABC Type Grouping based on the cost or fast moving type of a part.
Folio No. Folio number is a unique number which can be used to match the page number of the manual store register.
Kit If the current part is made up of several parts then kit is enabled.
Minimum Stock Level Minimum stock level is the amount of quantity of the part number which is always required in the store. Once the quantity goes below the minimum quantity a remainder is generated.
Re-order Level Re-order level is the amount of quantity below which a part is required to be ordered.
Note Any other information associated with the part is entered in the note.
