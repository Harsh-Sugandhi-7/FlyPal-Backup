Add/Edit/Delete Enquiry Item

To reach the Enquiry Item screen click Entries link, Select Enquiry link, You get List of Enquiry screen. Click Add New button on List of Enquiry screen, You get Enquiry Details screen. Again click Add button on Enquiry Details screen, You get Enquiry Item screen. 

How to Add New Enquiry Item ?
  1. Enter all the information & click Ok button, The record is added successfully in the Enquiry Item List.
  2. After adding click Save button on Enquiry Details screen to save the current record.
How to Edit The Enquiry Item ?
  1. Click Edit link on the selected record, You get Enquiry Item screen.
  2. After editing click Ok button, The updated record is added in the Enquiry Item list.
  3. Again click Save button on Enquiry Details screen to save the current record.
How to Delete The Enquiry Item ?
  1. Click Remove link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.
  3. After deleting click Save button to save the current record.

Enquiry Item Details screen contains following buttons :

Button Name Action
Ok OK button to save the Enquiry Item information.
Back Back button to return back to the Enquiry Details screen.

Enquiry Item Details screen contains following fields :

Field Name Field Description
Sr. No. Sr. No. is auto generated.
Part No. The Part No. is an alphanumeric code to identify any part. It must be unique (e.g. 000-170000-23).
Description Description field describes the part (e.g. GLARE SHIELD L.H.).
Quantity You can enter the quantity of that Enquiry item (e.g. 12.00).
Applicable To You can select the Model to which the part is applicable. It may be Aircraft, Engines or Ground Equipment etc.
Remark You can enter any remark for this entry in the Enquiry item.
Note Any other information associated with that Enquiry is entered in the note.

Note:
For selecting the Part & it's Description, click on the Icon of Part No. field, You get Part Stock Status List screen. Search a particular record & click Select link, The selected Part information is added in the Enquiry Item screen.
