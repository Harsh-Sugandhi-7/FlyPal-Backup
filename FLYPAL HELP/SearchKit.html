Search Inspection Kit

You can search Kit information on this screen. For searching the Kit information, go through following steps :-

How to Search The Inspection Kit ?

  1. Search a particular record & click Find Now button. You can Search the Inspection Kit from following way :-
    • All : From this you search all the records of Inspection Kits.
    • Name : From this you search the Kit by Inspection Kit name. For searching this you have to enter the name of Inspection Kit.
  2. By default searching record is display in the Inspection Kit list.

Inspection Kit List screen contains the following buttons :

Button Name Action
Find Now Find Now button to search the Inspection Kit.
Add New Add New button for adding new Inspection kit.
Close Close button to close the screen.
