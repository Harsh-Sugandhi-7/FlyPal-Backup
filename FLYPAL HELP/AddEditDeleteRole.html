Add/Edit/Delete Role

To reach the Role screen click User Manager, Select User Rights, You get User screen. Click UserRole button, You get User's Role screen. Again click Roles button, You get Role screen. You can Add/Edit/Delete Role on this screen. For adding Role of a selected user, go through following steps :-

How to Add New Role ?

  1. Enter the Role of user & click Save button to save the record.

How to Edit The Role ?

  1. Select the Role of user from list & click Edit button.
  2. After editing click Save button to save the record.

How to Delete The Role ?

  1. Select the Role from list and click Delete button, You get a message box for confirmation.
  2. Click Yes for deletion and No for cancel the action.

Role screen contains following buttons:

Button Name Action
Save Save button to save the user's role.
Permissions Permissions button to assign the permissions to the user.
New Add button for adding new role.
Edit Edit button to edit the selected role.
Delete Delete button to delete the selected role.
Close Close button to close the screen.

Note:
You can assign the Permissions to the selected user. For this click Role Permissions button on Role screen, You get Permission screen. Click the Checkbox to assign the permissions & click Close button. After that click Save button on Role screen to save the assigned permissions.
