Add/Edit/Delete Charge

To reach the Charge Information screen click Entries link, Select Sales Order link, You get List of Sales Order screen. Click Add New button on List of Sales Order screen, You get Sales Order Details screen. Click Add button on Sales Order Details screen, You get Sales Order Charge screen. Again click on the Icon of Charge Name field, You get Charge Information screen.

How to Add New Charge ?

  1. Enter all the information & click Add/Edit button to add the record in the list.

How to Edit The Charge ?

  1. Click Edit link which you want to edit the record.
  2. After editing click Add/Edit button, The updated record is added successfully in the Charge List.

How to Delete The Charge ?

  1. Click Delete link on the selected Charge, You get a message box for confirmation
  2. Click Yes for deletion & No for cancel the action.

Charge Information screen contains following fields :

Field Name Field Description
Charge Name It is the name of the charge (e.g. Service charge).
Percent Type The percentage type may be Fixed or Variable. You can select it from drop down list.
Charge Type The charge type is on Basic amount, on Particular charges or on Total amount. You can select it from drop down list.
Sign It may be Plus or Minus. If you select Plus then it's Total Other Charges can be added in the Grand Total. And if you select Minus then it's Total Other Charges can be deducted from the Grand Total.
Percentage You can enter the percentage of the charge in percentage field. The percentage field is not compulsory if you select the Percent Type "None" (e.g. 4.40).

Charge Information screen contains following buttons :

Button Name Action
Add/Edit Add/Edit button to add/edit the charge information.
Back Back button to return back to the Sales Order Charge screen.
