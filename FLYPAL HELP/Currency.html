Currency

To reach the Currency Information screen click Master link, Select Currency link, You get Currency Information screen. You can Add/Edit/Delete Currency information on this screen.

What do you want to do ?

  • Add New Currency
    Click on this link to see the information about how to Add new Currency.
  • Edit Currency
    Click on this link to see the information about how to Edit the Currency.
  • Delete Currency
    Click on this link to see the information about how to Delete the Currency.

Currency Information screen contains following fields :

Field Name Field Description
Currency Name The name of the currency (e.g. Rupees).
Symbol It is the symbol of currency (e.g. Rs).
Conversion Factor It is the conversion factor of that currency (e.g. 1.00).

Currency Information screen contains following buttons :

Button Name Action
Add/Edit Add/Edit button to add/edit the Currency information.
Close Close(Alt+C) button to close the screen.
