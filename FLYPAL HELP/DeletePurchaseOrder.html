Delete Purchase Order

You can delete the Purchase Order information on this screen. For deleting the Purchase Order information, go through following steps :-

How to Delete The Purchase Order ?

  1. Search a particular record & click Find Now button. You can Search the Order from following way : 
    • All : From this you search all the records of Order.
    • Date : From this you can search the Order by Date. You can search the Order Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates.
    • Order : From this you search the Order by Order number. For searching this you have to select the Order Text from drop down list & also enter the number which you want to search. 
    • Internal Order No. : From this you search the Order by internal order number. For searching this you have to enter the Internal Order Number.
    • Part No. : From this you search the Order by Part Number. For searching this you have to enter the part number.
    • Vendor : From this you search the Order by Vendor name. For searching this you have to enter the vendor name.
    • Quotation No. : From this you search the Order by Quotation No. For searching this you have to enter the quotation number.
    • Status : From this you search the Order by Status. For searching this you have to select the status from drop down list. The status may be Opened, Authorized, Amended or Cancelled.
  2. Click Delete link which you want to delete the record, You get a message box for confirmation.
  3. Click Yes for deletion and No for cancel the action.
