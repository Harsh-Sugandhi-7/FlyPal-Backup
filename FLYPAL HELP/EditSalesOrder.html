Edit Sales Order

You can edit the Sales Order information on this screen. For editing the Sales Order information, go through following steps :-

How to Edit The Sales Order ?

  1. Search a particular record & click Find Now button. You can Search the Sales Order from following way : 
    • All : From this you search all the records of Sales Order.
    • Date : From this you can search the Sales Order by Date. You can search the Sales Order Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates of Sales Order.
    • Sales Order : From this you search the Sales Order by Sales Order number. For searching this you have to select the Sales Order Text from drop down list & also enter the number which you want to search. 
    • Part Number : From this you search the Sales Order by Part Number. For searching this you have to enter the part number.
    • Vendor : From this you search the Sales Order by Vendor name. For searching this you have to enter the vendor name.
    • Quotation : From this you search the Quotation by Quotation number. For searching this you have to select the Quotation Text from drop down list & also enter the number which you want to search. 
    • Status : From this you search the Sales Order by Status. For searching this you have to select the status from drop down list. The status may be Opened, Authorized or Cancelled.
  2. Click Edit link which you want to edit the record, You get Sales Order Details screen.
  3. After editing click Save button, The updated record is added in the Sales Order List.

Note:
You can edit the Sales Order only when it is Opened.
