Expiry Date Report

To reach the Expiry Date Report click Reminders link, Select Expiry Date link, You get Expiry Date Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Date : From this you can search the Expiry Date by Start Date. For searching this you have to select the Start Date from drop down list.
  • Range : From this you search the Expiry Date by Date Range. For searching this you have to select the Date Range from drop down list.
  • Store : From this you search the Expiry Date by Store. For searching this you have to select the Store from drop down list.
  • Category : From this you search the Expiry Date by Category. For searching this you have to select the Category from drop down list.
  • Nomenclature : From this you search the Expiry Date by Nomenclature. For searching this you have to select the Nomenclature from drop down list.
  • Part No./Description : From this you search the Expiry Date by Part Number or Description. For searching this you have to click Select link on Part List.
