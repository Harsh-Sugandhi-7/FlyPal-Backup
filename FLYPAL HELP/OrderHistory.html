Order History Report

To reach the Order History Report click Reports link, Select Order History link, You get Order History Search Criteria screen. Select the criteria & click Display button, The searching report is display in the report screen. You can search the report from following ways :-

  • Date Range : From this you can search the Order History by Date. You can search the Date by All, Last 1 week, Last 1 Month, Last 1 Quarter, Last 1 year, Current Financial Year & Between Dates. For Between Dates criteria you have to enter the starting & ending dates.
  • Vendor : From this you search the Order History by Vendor Name. For searching this you have to select the vendor from drop down list.
  • Part No./Description : From this you search the Order History by Part Number or Description. For searching this you have to click Select link on Part List.
