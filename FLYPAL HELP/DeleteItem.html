Delete Part

You can delete the Part information on this screen. For deleting the Part information, go through following steps :-

How to Delete The Part ?

  1. Search a particular record & click Find Now button. You can Search the Part from following way :
    • All : From this you search all the records of Part.
    • Part No. : From this you search the Part by number. For searching this you have to enter the number of Part.
    • Description : From this you search the Part by description. For searching this you have to enter the description of Part.
    • Nomenclature : From this you search the part by nomenclature. For searching this you have to enter the Nomenclature name.
    • Category : From this you search the part by category. For searching this you have to enter the name of Category.
    • Unit : From this you search the part by unit. For searching this you have to enter the name of Unit.
    • Location : From this you search the part by Location. For searching this you have to enter the name of the location.
  2. Click on Delete link which you want to delete the record, You get a message box for confirmation.
  3. Click Yes for deletion and No for cancel the action.

Note:

  • For deleting the Part, You have to first delete the Opening Stock of that Part.
  • You can not delete those Part which are already links to other records.
