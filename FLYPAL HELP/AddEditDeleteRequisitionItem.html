Add/Edit/Delete Requisition Item

To reach the Requisition Item screen click Entries link, Select Requisition link, You get List of Requisition screen. Click Add New button on List of Requisition screen, You get Requisition Details screen. Again click Add button on Requisition Details screen, You get Requisition Item screen. 

How to Add New Requisition Item ?
  1. Enter all the information & click Ok button, The record is added successfully in the Requisition Item List.
  2. After adding click Save button on Requisition Details screen to save the current record.
How to Edit The Requisition Item ?
  1. Click Edit link on the selected record, You get Requisition Item screen.
  2. After editing click Ok button, The updated record is added in the Requisition Item list.
  3. Again click Save button on Requisition Details screen to save the current record.
How to Delete The Requisition Item ?
  1. Click Remove link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.
  3. After deleting click Save button to save the current record.

You can Add/Delete Aircraft | Add/Delete Model on this screen.

Requisition Details screen contains following buttons :

Button Name Action
Add Add button for adding an Aircraft in Aircraft List.
Add Add button for adding the Model in Model List.
Ok Ok button to save the Requisition Item information.
Back Back button to return back to the Requisition Details screen.

Requisition Item screen contains following fields :

Field Name Field Description
Sr. No. Sr. No. is auto generated.
Part Number The Part No. is an alphanumeric code to identify any part. It must be unique (e.g. 000-170000-23).
Description Description field describes the part (e.g. GLARE SHIELD L.H.).
Quantity You can enter the quantity of that Requisition item (e.g. 12.00).
Remark You can enter any remark for this entry in the Requisition item.
Note Any other information associated with that Requisition is entered in the note.

Note:
For selecting the Part & it's Description, click on the Icon of Part No. field, You get Part Stock Status List screen. Search a particular record & click Select link, The selected Part information is added in the Requisition Item screen.
