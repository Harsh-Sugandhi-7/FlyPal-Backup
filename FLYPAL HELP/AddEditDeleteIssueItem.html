Add/Edit/Delete Issue Item

To reach the Issue Item screen click Entries link, Select Goods Issue link, You get List of Issue screen. Click Add New button on List of Issue screen, You get Issue Details screen. Again click Add button on Issue Details screen, You get Issue Item screen. 

How to Add New Issue Item ?

  1. Enter all the information in Issue Item screen & click Ok button, The record is added successfully in the Issue Item List.
  2. After adding click Save button on Issue Details screen to save the current record.

How to Edit The Issue Item ?

  1. Click Edit link on the selected record, You get Issue Item screen.
  2. After editing click Ok button, The updated record is added in the Issue Item List.
  3. Again click Save button on Issue Details screen to save the current record.

How to Delete The Issue Item ?

  1. Click Remove link on the selected record, You get a message box for confirmation.
  2. Click Yes for deletion & No for cancel the action.
  3. After deleting click Save button to save the current record.

Issue Item screen contains following buttons :

Button Name Action
Ok Ok button to save the Issue Item.
Back Back button to return back to the Issue Details screen.

Issue Item screen contains following fields :

Field Name Field Description
Quantity Here quantity mean the total stock. Quantity is editable but it never be greater than it's receipt quantity. 
Returnable Returnable means the parts has been given for loan or replacement. This part is expected back for which you are tracking or monitoring.
Remarks You can enter any remark for this entry in issue item screen.
Note Any other information associated with that issue is entered in the note field.

Note:
The fields of Issue Item & Issue Item Information are selected when you click on the Icon of Part No. field, You get Part Stock Status List screen. Search a particular record & click Select link on any record, You get information of Pending Item Stock List. Again click Select link, The information of Issue Item & Issue Item Information is added in the Issue Item screen.
